# 나전, 하나 (NAJEON, HANA) — ecommerce concept

나전의 빛을 현대 스트릿웨어로 번역한 단일 페이지 커머스 콘셉트입니다. 별도 프레임워크나 유료 라이브러리 없이 HTML, CSS, JavaScript로만 구성되어 있습니다.

## 로컬에서 열기

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. `index.html`을 직접 열어도 대부분 작동하지만, 웹폰트와 일부 브라우저 기능 검수를 위해 로컬 서버 사용을 권장합니다.

## 파일

- `index.html`: 브랜드 카피와 전체 페이지 구조
- `styles.css`: 반응형 디자인, 자개광, 이미지 마스크, 섹션 와이프·스크롤 전환 애니메이션
- `script.js`: 상품 모달, 사이즈 선택, 장바구니, 모바일 메뉴, 뉴스레터 데모
- `assets/`: 프로젝트 전용으로 생성한 패션·공예 이미지 10종

## 실제 출시 전에 바꿀 항목

1. 브랜드명은 `나전, 하나 (NAJEON, HANA)`로 반영되어 있습니다. 상표 출원 및 도메인 확정 시 영문 표기 등을 최종 점검하세요.
2. `script.js`의 `products` 객체에서 상품명·가격·설명을 수정할 수 있습니다.
3. 현재 장바구니와 뉴스레터는 프론트엔드 데모입니다. Shopify, 아임웹, 카페24 또는 자체 백엔드 연결이 필요합니다.
4. 실제 제품이 나오면 생성 이미지 대신 동일한 구도의 실사 촬영본으로 교체하세요.
5. `index.html`의 두 `https://www.instagram.com/` 주소를 실제 브랜드 계정 주소로 교체하세요.
6. 연락처·사업자 정보·이용약관·개인정보처리방침 링크를 연결하세요.

이 콘셉트는 `Instagram-first · Online-only` 운영을 전제로 하며, 팝업스토어·오프라인 매장 관련 콘텐츠는 포함하지 않습니다.

공예 섹션의 장인 이미지는 특정 실존 장인이나 실제 협업을 기록한 사진이 아닌 브랜드 콘셉트용 연출 이미지입니다. 실제 장인과 협업하게 되면 정식 허락을 받은 촬영본과 정확한 크레디트로 교체하세요.

## 폰트 라이선스

Google Fonts에서 제공하는 `Noto Sans KR`와 `Noto Serif KR`를 사용합니다. Google Fonts의 글꼴은 오픈소스 라이선스로 제공되며 상업 프로젝트에 사용할 수 있습니다. 배포 전 각 글꼴의 현재 라이선스 파일도 함께 보관하는 것을 권장합니다.
