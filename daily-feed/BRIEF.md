# 매일 인스타그램 캐러셀 제작

## 현재 상태
- 사용자가 요청한 결과: 하루 게시물 1개, 이미지 여러 장, 설명글 AI 작성, 업로드는 사용자 직접.
- 기본안: 게시물당 세로 4:5 이미지 5장과 한국어 설명글 1개.
- 예약 실행과 유료 API 연결은 아직 설정되지 않음.
- 브랜드명: `나전, 하나` (영문 표기 `NAJEON, HANA`). 출시일/가격은 미확정. 기존 프로젝트의 나전·검정·빛·현대 스트릿웨어 콘셉트를 작업 기준으로 사용.

## 콘텐츠 기준
- 검정 옷과 섬세한 포인트를 좋아하는 잠재 고객에게 시각적인 취향 발견을 제공한다.
- 콘텐츠 축: 포인트 위치 비교, 빛과 소재, 전통 형태를 현대적인 의복 그래픽으로 해석하기.
- AI 콘셉트 이미지로 제작한다. 실물 제작/촬영/실험/장인 협업이 있었다고 쓰지 않는다.
- 실제 제품 소개는 사용자가 제공한 확정 제품 자료를 기준으로 한다.
- 문화/역사 사실을 설명할 때는 출처를 확인한다. 창작 문양을 실제 유물이라고 소개하지 않는다.
- 브랜드 가칭, 판매 가격, 출시 일정은 임의로 확정하지 않는다.

## 한 게시물의 구성
1. 표지: 한눈에 이해할 수 있는 시각적인 질문이나 비교.
2. 관찰: 첫 번째 사례를 크게 보여준다.
3. 비교: 두 번째 사례. 비교 변수를 명확하게 유지한다.
4. 확장: 세 번째 사례 또는 실제 스타일링으로 연결한 해석.
5. 마무리: 한 가지 취향 질문 또는 다음 콘텐츠 예고.

다섯 장을 각각 독립된 이미지 파일로 생성한다. 한 장에 다섯 슬라이드를 붙인 콘택트시트는 납품하지 않는다. 각 장의 역할을 달리하되 같은 게시물 내의 배경, 색감, 타이포그래피, 소재, 의복 형태는 일관되게 유지한다.

## 이미지 기준
- 비율 4:5 세로. 검정, 차콜, 아이보리 글자, 제한적인 청록/자주 자개광.
- 이미지가 주인공. 텍스트는 짧고 읽기 쉽게. 한 장에 핵심 문장 하나.
- 의복은 현대적이고 절제된 형태. 과도한 판타지 광원, 장식, 가상의 상표를 넣지 않는다.
- 한국어 오탈자, 깨진 글자, 위치 비교 오류, 불필요한 제품 변형을 시각적으로 확인한다.
- 이미지 생성 도구로 제작한다. API 연결은 별도 선택 사항이며 현재 지침 자체는 실행 프로그램이 아니다.

## 설명글 기준
- 한국어 150~350자 정도. 사진의 관찰 → 취향에 대한 해석 → 자연스러운 질문 순서.
- 추상적인 명언 반복, 과장된 구매 유도, 근거 없는 유행/인기 주장은 피한다.
- AI 창작 이미지로 실물과 혼동될 경우 'AI로 구성한 디자인 콘셉트 이미지입니다.'라고 명시한다.
- 실제로 게시할 후속 콘텐츠가 준비되어 있지 않으면 다음 날 게시를 약속하지 않는다.
- 관련성 있는 해시태그 3~5개. 가짜 브랜드명이나 무관한 인기 해시태그를 넣지 않는다.

## 반복 제작 절차
1. 이 지침, content-plan.json, history.json을 읽는다.
2. 다음 미제작 주제를 고른다. 최근 게시물과 표지 문장/구도/주제를 비교해 중복을 줄인다.
3. 각 장의 역할과 이미지 프롬프트를 먼저 작성한다.
4. 이미지 5장을 생성하고 시각적으로 검수한다. 필요한 장만 수정한다.
5. 설명글과 대체텍스트를 작성하고 이미지 내용과 대조한다.
6. 날짜별 폴더에 01~05 이미지, caption.txt, prompts.md, metadata.json을 저장한다.
7. 이미지 5장이 모두 확인되었을 때만 ready_for_review로 기록한다. 실패는 failed/partial로 남기고 파일을 덮어쓰지 않는다.
8. 인스타그램에 게시하지 않는다. 사용자에게 폴더와 미리보기를 전달한다.

## 실행 요청문
이 폴더의 BRIEF.md와 content-plan.json, history.json을 읽고 오늘 검토할 캐러셀 게시물 한 세트를 제작해 줘. 기본 5장의 독립 이미지와 한국어 설명글 1개, 해시태그, 장별 대체텍스트를 만들어 날짜별 폴더에 저장해. 이미지를 직접 생성하고 검수하며, 프롬프트만 작성하고 완료했다고 하지 마. 부분 실패는 상태에 남겨. 업로드는 내가 직접 한다.
